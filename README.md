# AgentGate

基于 Rust + GPUI + russh 构建的桌面端菜单栏 SSH 安全隔离中转工具（支持 macOS / Windows / Linux）。

## 核心特性

- **凭据本地强隔离**：仅在 `127.0.0.1:<随机未占用端口>` 暴露本地 SSH 服务，向 AI Agent 仅提供机器代号（`codename`）与 24 位高熵临时密码或专用 Ed25519 密钥；真实远端 IP、端口、账号与密钥经 `AES-256-GCM` 加密存储于本机 `vault.enc`，永不进入 Agent 配置或上下文。
- **出站代理支持**：每条机器独立支持直连、`SOCKS5` 与 `HTTP CONNECT` 代理转发。
- **全操作二次确认**：启动/停止中转、新建/修改/删除主机、轮换凭证、复制 Agent 配置均经过内置模态确认框。
- **菜单栏常驻**：运行于系统菜单栏/状态栏，不占用 Dock 或任务栏图标。
